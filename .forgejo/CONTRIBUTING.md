# Contributing

Thank you for your interest in contributing to this project!

We expect that you already have a background in Android development and are experienced with it. As
such, this will not cover the architecture or structure of Navic and will instead touch on
contribution guidelines as to not waste your time.

## Rules

1. Format code contributions and update copyright notices.
	* It is recommended that you enable code actions on save in Android Studio.
	  ![](https://files.catbox.moe/2t67hs.png)
2. PRs must have a limited scope and have one feature or fix per PR.
3. PRs, commits and branches must follow
   the [conventional commit](https://www.conventionalcommits.org/en/v1.0.0/) format.
4. PRs should not be made on the `master` branch. Create a new branch for your contribution.
5. PRs with UI changes should include screenshots.
6. Avoid additional dependencies. We want to keep the APK size low and build times fast.
7. Avoid working on an issue if somebody has already been assigned to it.

Exemptions to these rules may be made, as long as you coordinate with us before doing so.
